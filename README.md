# Arena 模型助手 1.2.9

Chrome / Edge Manifest V3 扩展。点击工具栏图标打开侧边栏，默认在当前 Arena 页面切换到 Agent 模式，按设置的数量创建独立会话，逐个发送三条数字探测提示词，并使用 Ikaleio 引擎验证模型。

## 安装或更新

1. Chrome / Edge 116 或更新版本，打开扩展管理页并开启开发者模式。
2. 首次安装：解压 `Arena-Model-Assistant.zip`，点击“加载已解压的扩展程序”，选择含 `manifest.json` 的目录。
3. 已加载本工作目录：在扩展管理页点击此扩展的“重新加载”。本次新增 scripting 权限，如浏览器提示网站访问权限，请允许 Arena 网站访问。
4. 从旧版更新后刷新一次 Arena 页面，清除旧版页面监听器。点击扩展图标打开侧边栏。

ZIP 需要先解压，不能直接拖入浏览器作为商店签名扩展安装。没有额外构建步骤或运行依赖。

## 使用

- 打开已登录、可发送消息的 Arena 页面，点击“开始抽模型”。插件实时读取活动标签页，先检查连接、必要时补注入页面脚本，再检查 Agent 模式。切换到 `/agent` 后会重新建立连接。
- 请先发送或清空自己的输入草稿；插件不会覆盖未发送内容。任务中保持同一对话，避免刷新、切换模式或手工发送。保持侧边栏打开；本版不提供关闭侧边栏后的任务恢复。
- 三轮样本来自新产生的回复块，等待页面结束生成后读取。最低有效数字为 165（300 的 55%，与上游算法一致），可在指纹设置中提高至 300。
- “停止”取消后续轮次及后续重命名，并尝试点击页面停止生成；API 模式会中断当前请求。页面已经收到的消息仍会保留。
- 默认将识别到的第一候选名称用于当前会话重命名。只操作标题对话框，不会写入聊天输入框；如果找不到菜单或无法确认保存，会保留识别结果并显示原因。网站页面变化可能影响此功能。
- “创建会话”打开 `/agent` 新会话入口；“鹈鹕骑自行车测试”发送 EasyAI.offline.exe 同款提示词：创建只展示自动循环 SVG 动画的 HTML，绘制鹈鹕骑自行车，不添加解释、按钮或交互。
- “抽取模型数量”可设置 1–20 个。第一个模型使用当前会话，后续模型自动打开新的 Agent 会话；每个会话完成三轮取样后再进入下一个。
- 自动重命名默认要求 Ikaleio 置信度至少 90%，可在“指纹设置”中调整。低于阈值不会改名；验证结果记录为 `https://lm.ikale.io/` 的同源 Fingerpoint 引擎结果。
- “单个会话回复超时”默认 3 分钟，可设置为 1–30 分钟；超时会停止生成并优先删除该会话。若 Arena 当前版本只提供 Archive/归档菜单，则自动归档并在结果中标明，再继续抽取下一个，最多尝试目标模型数的 3 倍。
- 自动重命名会模拟 Arena 的实际操作：定位当前会话，触发悬停显示右侧三点按钮，选择 Rename/重命名，填写模型名并确认保存。
- 任务完成反馈框会先按页面 `lang`、文字脚本和按钮词典自动判断语言，支持中文、英语、日语、韩语及多种欧洲和亚洲语言；即使按钮只有勾选、叉号、编辑图标也能识别。仅当检测到完整的任务反馈选项组时发送 Esc，不会关闭普通问号弹窗。
- 如果 Arena 弹出 Cloudflare/reCAPTCHA 等安全验证，插件会暂停当前抽样的超时计时，提示手动完成验证，验证界面消失后自动继续；插件不读取、识别或绕过验证码。
- 侧边栏按 EasyAI.offline.exe 的方式，在当前 `arena.ai` 页面带登录 Cookie 请求 `/api/me/pulse` 显示真实额度；未登录、拒绝或限流时会显示查询状态。账号工作台保存本机账号备注，不支持批量注册或隔离浏览器账号。

## API 与开源识别

在非 Arena 标签页开始识别时，使用填写的 Base URL、API Key、模型名和协议请求样本，支持 Chat Completions、Responses 和 Anthropic Messages。API 地址自动补齐 `/v1` 及对应路径；自定义网关需支持这些协议。每组最多 4096 输出 token、2 分钟超时。

`https://lm.ikale.io/` 是 Fingerpoint Detector 页面，不是模型生成 API 的 Base URL。扩展采用 [Ikaleio/lm-detector](https://github.com/Ikaleio/lm-detector) 的原始 `shared/fingerprint-core.js`、对应版本 `unified_bank.json`，在本地执行与该网站相同的全局稳健数字指纹算法，并将验证来源、阈值和通过状态写入结果。上游提交号与 MIT 许可见 `vendor/UPSTREAM.txt` 和 `vendor/LICENSE`。

模型结果是指纹库内的相对分数，不能证明真实后端身份；未收录模型、代理路由、多模型混合及提示词改动会影响结果。低于上游 85% 相对分数阈值会显示“证据不足”。

API Key 保存在本机扩展存储，发送给所配置的 API 服务，不发送给 lm.ikale.io。历史记录不保存 API Key。扩展保留通用主机权限以支持用户自定义 API 地址；自动页面脚本仅在 Arena 域名运行。
